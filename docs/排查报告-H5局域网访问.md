1. **网络是 Public，不是 Private。** 你要求的「专用网络」放行规则，在这台机器上连着 `xju_5.8G` 时**不会生效**。所以脚本除了加 Private 规则，还补了一条 Public 规则。
2. **Windows 防火墙里「阻止」优先级高于「允许」。** 只加一条 allow 规则，仍会被那两条 `node.exe` 的 block 规则拦掉。所以必须同时把 TCP 那条阻止规则禁用（保留规则本体，只是禁用，随时能恢复）。

User    = ZHIZUN\lenovo

修改 Windows 防火墙规则需要管理员令牌，当前会话不具备，工具内无法提权，也不应绕过。

双击后会弹 UAC，点「是」即可，脚本做三件事：

1. 加 TCP 5180 入站允许（Private，按你的要求）
2. 加 TCP 5180 入站允许（Public，当前实际网络类型）
3. 禁用 `node.exe` 的 TCP Public 阻止规则

### 步骤 4：排查结论（三选一）

| 可能原因 | 判定 | 依据 |
| --- | --- | --- |
| **Windows 防火墙** | ✅ **主因，确定** | 网络为 Public + 存在 `node.exe` 的 Public 入站阻止规则（端口 Any）命中本服务进程 + 无任何 5180 允许规则。本机访问走回环不受入站过滤，外部设备走入站被拦，现象完全吻合 |
| **vite / 服务 host 监听配置** | ❌ **排除** | 服务是 `serve.mjs` 且 `HOST='0.0.0.0'`，实测 `0.0.0.0:5180 Listen`；`vite.config.js` 里 `server.host: true` 与 `preview.host: true` 也都已开启。另外当前跑的根本不是 vite dev（那是 5174 端口），5180 是静态服务器 |
| **路由 / WiFi 网段隔离（AP 隔离）** | ⚠️ **暂不能排除，需手机侧复测** | 校园网 `xju_5.8G` 常见客户端隔离。本机无法验证「另一台设备能否到达本机」，只有你手机复测能确认。若防火墙修完仍不通，基本就是它 |

**根因链路：**

```
手机 ──(同 WiFi)──> 10.107.154.126:5180
                     │
                     ├─ 服务在 0.0.0.0 正常监听           ✅

                     └─ Windows 防火墙入站                 ❌
                          ├─ 网络类别 Public
                          ├─ 无 5180 允许规则
                          └─ node.exe Block(Public, Any) ← 命中服务进程
```

**另一个容易踩的点（不是根因，但会让人以为没配好）：**
服务启动时会打印多个「手机上打开」地址，其中：

## 三、如果手机还是打不开

按下面顺序判断，能快速区分「防火墙没生效」和「WiFi AP 隔离」：

| 手机上的现象 | 说明 | 处理 |
| --- | --- | --- |
| 一直转圈、最后「连接超时」 | 多半是防火墙仍拦着，或 AP 隔离 | 先确认脚本确实以管理员运行成功、规则表如预期 |
| 立刻「无法访问 / 拒绝连接」 | 网络层是通的，服务没应 | 回电脑确认 5180 仍在 `0.0.0.0` 监听 |
| 手机 IP 不是 `10.107.x.x` | 手机和电脑不在同一网段 | 换同一个 WiFi，或用下面的热点方案 |

**最快的绕过方案（若判定为校园网 AP 隔离）：**

1. 手机开「个人热点」，电脑连上这个热点
2. 电脑上重新看 WLAN 的新 IP（`ipconfig`），假设是 `172.20.10.2`
3. 手机浏览器访问 `http://172.20.10.2:5180`
4. 手机热点一般不隔离客户端，这条路通常直接通

> 局域网 http 下 PWA 不能「添加到主屏幕」，但功能与数据全部正常，不影响本次复测。

两部手机（`172.28.17.239` 开热点的那部、`172.28.17.219` 另一部）都可以试，
预期 0.1~0.2 秒出首页。服务不用重启，一直在跑。

### 7.6 以后换网络怎么办（通用做法）

**IP 每次换 WiFi / 换热点都会变，必须重新查一次**，不要沿用旧地址。
在电脑上执行任一条即可拿到当前 WLAN 地址：

```bat
ipconfig | findstr "IPv4"
```

```powershell
(Get-NetIPAddress -AddressFamily IPv4 -InterfaceAlias WLAN).IPAddress
```

拿到结果后拼上 `:5180`，例如 `http://172.28.17.4:5180`。
注意忽略这几类**不能给手机用**的地址：`127.0.0.1`（本机）、
`169.254.x.x`（无效地址）、`172.24.224.1`（模拟器虚拟网卡）。

**想要一个不会变、也不依赖外部 WiFi 的稳定地址**：让**电脑**开移动热点
（设置 → 网络和 Internet → 移动热点 → 从 WLAN 共享），手机连电脑的热点，
然后访问 `http://192.168.137.1:5180`。此时电脑是网关，不受任何 AP 隔离影响，
地址也固定，最适合发给同学演示。
